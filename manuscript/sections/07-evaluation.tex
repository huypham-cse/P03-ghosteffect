\subsection{Model-based recovery comparison}
\label{sec:setup}
The default model contains eight app profiles, persistent reader errors, correlated VLM errors and a fallible Monitor.
Calibration uses whole effects; each policy sees the same \SimN{} interrupted workflows (Table~\ref{tab:planner}).
The user can answer incorrectly, so total duplicate/loss rates include user errors as well as planner decisions.
The guaranteed quantity $P_{\mathrm v}$ instead counts committed effects retried by the planner itself. The confidence $\delta$ follows \S\ref{sec:theory-cal}.
Appendix~\ref{app:extra} records the complete model, budgets, confidence intervals and paired tests.
